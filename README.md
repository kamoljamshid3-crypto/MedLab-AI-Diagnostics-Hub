# 🧪 MedLab AI Diagnostics Hub

### AI-assisted CBC Clinical Decision Support Platform

MedLab AI Diagnostics Hub — umumiy qon tahlili (CBC) natijalarini strukturali tahlil qilish, muhim laborator o‘zgarishlarni aniqlash va shifokorga klinik qaror qabul qilish jarayonida yordam berish uchun ishlab chiqilgan HealthTech platforma.

> ⚠️ **Muhim:** Ushbu loyiha klinik qarorlarni qo‘llab-quvvatlovchi MVP/prototip hisoblanadi. Tizim mustaqil tashxis qo‘ymaydi va davolashni belgilamaydi. Yakuniy klinik qaror malakali shifokor tomonidan bemorning klinik holati, anamnezi va laboratoriyaning amaldagi reference intervalari asosida qabul qilinadi.

---

## 🎯 Loyiha maqsadi

Laboratoriya natijalarini tahlil qilish jarayonini tezroq, tushunarliroq va tizimliroq qilish.

MedLab AI Diagnostics Hub:

- 🩸 CBC ko‘rsatkichlarini qabul qiladi
- 📊 Laboratoriya natijalarini strukturali baholaydi
- 🔎 Muhim og‘ishlarni aniqlashga yordam beradi
- 🧠 Klinik patternlarni ajratishga yordam beradi
- 💡 Shifokor uchun tavsiyalar va keyingi baholash yo‘nalishlarini ko‘rsatadi
- 📄 Natijalarni hisobot ko‘rinishida taqdim etadi

## 🧬 CBC tahlili

Platformada quyidagi asosiy ko‘rsatkichlar bilan ishlash mumkin:

| Ko‘rsatkich | Birlik |
|---|---|
| Gemoglobin | g/dL |
| WBC | ×10⁹/L |
| Trombotsit | ×10⁹/L |
| RBC | ×10¹²/L |
| Neytrofil | % |
| Limfotsit | % |

Kelajakdagi versiyalarda CBC parametrlarini kengaytirish rejalashtirilgan.

## 🤖 AI / Clinical Decision Support

Platformaning asosiy konsepsiyasi — laboratoriya ma’lumotlarini oddiy raqamlar sifatida emas, balki klinik kontekst bilan birgalikda ko‘rib chiqish.

Tizim quyidagi jarayonni qo‘llab-quvvatlaydi:

**Laboratoriya natijasi → Pattern aniqlash → Klinik kontekst → Ehtimoliy yo‘nalish → Shifokor bahosi**

AI komponentlari rivojlantirilishi bilan tizimga yanada murakkab klinik pattern recognition va decision-support funksiyalari qo‘shilishi mumkin.
